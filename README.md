# We-Are · marca

Logos oficiales de We-Are, públicos para que las skills de Claude (PowerPoint, PDF, Word) los puedan descargar.

Todas las versiones van solo sobre fondo oscuro: letras en blanco y cohete en naranja (#f55726). No recolorear, redibujar ni deformar.
